========================================
   WVCXX MockLab - API Mock Server
========================================

Автор: WVCXX
Версия: 1.0.0
Описание: API мок-сервер c графическим интерфейсом

========================================
 ЧТО ЭТО?
========================================

MockLab - это фейковый сервер, который имитирует работу настоящего API.
Позволяет создавать мок-эндпоинты с любыми JSON-ответами без реального бэкенда.


========================================
 КАК ЗАПУСТИТЬ?
========================================
(в настоящий момент работает на бесплатном хосте, поэтому при первом запуске он загружается +- 60 секунд)

1. Установи зависимости Python:
   pip install fastapi uvicorn pydantic

2. Запусти бэкенд:
   python server.py

3. Открой index.html в браузере (двойной клик)

4. Готово! Сервер работает на http://localhost:8000

========================================
 ФУНКЦИИ
========================================

- Создание эндпоинтов (GET, POST, PUT, DELETE, PATCH)
- Настройка статус-кода и задержки ответа
- Включение/отключение эндпоинтов
- Поиск и фильтрация по методу
- Экспорт/импорт всех эндпоинтов в JSON
- Копирование URL эндпоинта

========================================
 ПРИМЕР ИСПОЛЬЗОВАНИЯ
========================================

1. Создай эндпоинт:
   - Path: /api/users
   - Method: GET
   - Response: {"users": ["Alice", "Bob"]}

2. В своём коде делай запрос:
   fetch('http://localhost:8000/api/users')

3. Получишь свой JSON-ответ
